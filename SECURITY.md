# Security Policy

## Supported versions

The latest release on `main` receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately via
[GitHub Security Advisories](https://github.com/swapnil-saal/agentic-react-starter/security/advisories/new),
or by email to **swapnil@saal.ai**.

Include what you found, how to reproduce it, and what an attacker could do
with it. You can expect an acknowledgement within a few days and an honest
assessment of whether and when it will be fixed.

## Scope

This is a starter template with no server, no authentication and no data
store. The most likely real issues are in the dependency tree, or in guidance
that leads users to write something insecure — both are in scope and worth
reporting.
